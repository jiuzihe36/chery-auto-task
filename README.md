# 奇瑞汽车App 每日积分自动化

每天自动：签到 → 分享帖子×2 → 发视频帖×2（奇瑞资讯混剪），顺带尝试优质帖/客户之声等高分任务（需人工审核，得分不保证）。

> 当前状态：**框架已搭好，API 地址待抓包填入**（奇瑞官方未开放接口文档，必须抓一次包才能跑通，见下文第3步）。

## 1. 每天能拿多少分（按你截图的规则）

| 任务 | 规则 | 是否可全自动 |
|---|---|---|
| 连续签到 | 每天签到送积分 | ✅ 稳拿 |
| 分享帖子 | +1/次，上限2分/天 | ✅ 稳拿 |
| 发视频帖 | +10/条，上限20分/天 | ✅ 稳拿（本仓库每天混剪2条） |
| 发表优质帖/帖子加精/被推荐/评论加精/客户之声 | +20~+500 | ⚠️ 机器只能保证"每天去发"，给不给分看官方审核 |

## 2. 仓库结构

```
src/chery_client.py  # 登录/签到/分享/发视频 的接口封装（ENDPOINTS 待填）
src/tasks.py         # 每日任务编排：登录→签到→分享→发视频→打卡记录
src/video_maker.py   # 奇瑞资讯混剪：raw素材 → 2条成品视频
videos/raw/          # 放你的原始素材（横/竖屏都行）
videos/out/          # 每天生成的成品（git忽略，由 CI 生成）
.github/workflows/daily.yml  # 每天早上8点（北京时间）自动跑
```

## 3. 让它跑起来（只需做一次，共3步）

### 第1步：填账号（GitHub 网页上点几下）

在仓库页面点 `Settings → Secrets and variables → Actions → New repository secret`，建两个：

- `CHERY_PHONE`：你的奇瑞App登录手机号
- `CHERY_PASSWORD`：登录密码（手机号+密码登录）

### 第2步：抓一次包，填接口地址（关键，约15分钟）

电脑上装 Charles（或安卓装 HttpCanary），手机连同 WiFi 并设代理，然后在奇瑞App里依次点：登录、签到、分享、发视频。
把抓到的域名和路径填到 `src/chery_client.py` 顶部 `BASE_URL` 和 `ENDPOINTS` 里（文件里有中文注释标了位置），提交一次即可，以后不用再抓。

### 第3步：放视频素材 + 手动跑一次

把2~3段奇瑞相关视频扔进 `videos/raw/`，然后在仓库页面点 `Actions → 每日积分任务 → Run workflow`，看日志里出现 `全部任务完成` 即成功。之后每天自动跑。

## 4. 安全提醒

- 私有仓库，不要公开（脚本含你的登录逻辑）。
- 混剪素材请用官方活动/自己实拍或已授权素材，避免纯搬运被判违规。
- token 只用一次：给你仓库建完后，去 https://github.com/settings/tokens 删掉那串 `ghp_` 即可，CI 靠 Secrets 运行，不依赖它。
